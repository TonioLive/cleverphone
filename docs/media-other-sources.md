## Identificación pendiente

- ZTE Nubia Focus 4G: el proveedor no incluye EAN. La ficha comercial de Tía Ecuador utiliza ese nombre, pero especifica T760 y un diseño que el fabricante asocia al Focus 5G. Se mantiene sin imágenes hasta que se confirme la referencia; el producto queda oculto por decisión del usuario.
- Qubo X230C 4G: el comercio denomina la referencia X-230BK/BKC 4G; el sufijo del proveedor se debe cotejar por EAN. La galería muestra ese teléfono exacto tipo C y se conserva la aclaración.

## Límites y decisiones

- Fnac A58 ofrece vistas de 340 px. Se usa una fotografía principal de Arpo y tres ángulos de Fnac; no se amplía artificialmente la resolución.
- Sunstech CELT25BL usa la composición azul oficial y tres recortes indicados como ampliación. No se utiliza la imagen negra de alta resolución para representar el modelo azul.
- Motorola G06 Power y Qubo P186BKC, X209BK 4G, X28 4G y X230C 4G completan las cuatro imágenes con detalles útiles del teclado, pantalla o cámaras a partir de fotografías reales; no se presentan esos recortes como otros ángulos.
- Denver y cuatro modelos Qubo adicionales se investigan en lotes paralelos y se entregan en sus correspondientes manifiestos.
